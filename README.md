# Voltage Multiplier Circuit

## Overview
This project demonstrates the working of a Voltage Multiplier Circuit using diodes and capacitors.

The circuit increases the DC output voltage without using a step-up transformer.

---

## Features
- Simple analog circuit
- Low cost implementation
- High voltage DC generation
- Easy hardware setup

---

## Components Used
- 1N4007 Diodes
- Capacitors
- Transformer
- Breadboard
- Connecting Wires

---

## Software Used
- Proteus (Optional)

---

## Working Principle
1. AC voltage is applied to the circuit.
2. Diodes control charging direction.
3. Capacitors store and add voltage levels.
4. Higher DC voltage is obtained at output.
